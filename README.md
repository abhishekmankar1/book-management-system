# Book Management System

A React-based Book Management System that allows users to:

- View Books
- Add Books
- Edit Books
- Delete Books
- Search Books
- Toggle Dark Mode

## Tech Stack

- React.js
- Tailwind CSS
- Axios
- React Router DOM
- MockAPI
- Vercel

## Features

- CRUD Operations
- Responsive Design
- Dark Mode
- API Integration
- Search Functionality

## Installation

Clone the repository:

git clone https://github.com/abhishekmankar1/book-management-system.git

Install dependencies:

npm install

Start the project:

npm start
